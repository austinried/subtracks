## What's new

- New **Song tap behavior** setting: choose whether tapping a song disables shuffle (the new default), keeps the current shuffle mode, or starts shuffled playback
- Syncing now gracefully updates the queue when the playing items change
- Android 17 local-network support: requests the required nearby devices permission when testing or saving a server on your local network
- Updated translations: Chinese Simplified (thanks BonexP via Weblate!)

## Performance

- Large shuffled queues use less memory by loading only the needed queue entries
