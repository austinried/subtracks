subtracks is an open source Android client for [Subsonic-compatible](http://www.subsonic.org/pages/api.jsp) servers ([Navidrome](https://www.navidrome.org/), [gonic](https://github.com/sentriz/gonic), [LMS](https://github.com/epoupon/lms), [Nextcloud Music](https://apps.nextcloud.com/apps/music) and more). It is written natively in Kotlin and Jetpack Compose and gives you clean, convenient access to your music in the style of a modern media player.

## Features

- Home screen to browse your library over many categories, genres, and more
- Album and artist artwork, shown full-resolution in the detail and now playing views
- Downloads with album, artist and playlist bulk downloads, download quality and a metered-connection toggle
- Search across albums, artists, playlists and songs, with per-list sort and filter controls
- Gapless playback, an editable queue you can reorder and jump through, and loop and shuffle modes
- Up next queue to add items into the currently playing queue without rewriting it
- Multiple server support with quick switching
- Stream quality (bitrate and format) settings for Wi-Fi and mobile and automatic switching
- Scrobbling and starred items, cached while offline and sent back to the server when online
- Media notification and headset/Bluetooth controls
- Adaptive theming from the current song's artwork

The full library is mirrored at sync, so browsing, searching, sorting and filtering all work without waiting on the server. Only media and artwork are fetched on demand, and not even that when they're already downloaded.

## Building

The project's entire toolchain is provided by a Nix flake. The default devshell provides JDK, Gradle and the Android SDK, so there is nothing to install by hand.

Therefore, to get started, you'll need to install Nix. I prefer [Lix](https://lix.systems/install/).

```sh
nix develop
gradle :app:assembleDebug
```

Test, lint and screenshot commands, plus the integration harness, are documented in [AGENTS.md](AGENTS.md). The architecture is described in [docs/architecture.md](docs/architecture.md).
